# Android integration: PK-057–PK-066

## Covered flow

1. Compose navigation starts on the locally persisted active shopping list.
2. Items can be added, edited, deleted, or pasted as multiple lines.
3. Every item has a quantity and either `EXACT_PRODUCT` or
   `FLEXIBLE_CATEGORY` rules with optional constraints.
4. Room keeps the draft through process restarts and network loss.
5. WorkManager retries pending creates, updates, and deletes when a network is
   available.
6. Matching displays up to five candidates with brand/package details and a
   clear unmatched option.
7. Location is requested only after an explicit user action. Manual latitude
   and longitude remain available when permission is denied. Precise
   coordinates stay only in the active in-memory calculation session; they
   are not placed in navigation state, Room, or DataStore.
8. The result screen consumes the PK-046–PK-056 recommendation contract and
   shows `SINGLE_STORE`, `RECOMMENDED_BALANCE`, and `LOWEST_PRICE`.
9. Each result exposes basket, route, duration, stops, total cost, savings,
   source/date information, store allocation, unresolved items, and the stock/
   checkout-price disclaimer.

## Local backend address

The default debug URL is `http://10.0.2.2:8080/`, which is correct for the
Android emulator. Copy `local.properties.example` to `local.properties` and set
`BACKEND_BASE_URL` to the Mac's LAN address when testing on a physical phone.
The value can also be supplied as the `BACKEND_BASE_URL` environment variable
or the Gradle `-PBACKEND_BASE_URL=...` parameter. Gradle parameters take
precedence, followed by environment variables and then `local.properties`.

A phone and the Mac must be on the same network when a LAN URL is used, and the
backend must remain running. An installable build that works outside the local
network should point to the HTTPS domain from `infra/compose.production.yaml`.

`X-Client-Token` is generated once, stored in DataStore, and attached to every
API request. No account is required.

## Verification

```bash
./gradlew testDebugUnitTest assembleDebug
./gradlew connectedDebugAndroidTest
```

The connected test is the Hilt/Retrofit/Room/DataStore smoke test and needs an
emulator or physical test device.
